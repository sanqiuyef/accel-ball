# 加速球自测记录

- 日期：2026-11-17
- 系统：Windows 10 x64 19045.6466，单屏 1920×1080，DPI 100%
- 编译器：MSVC 14.44.35207（VS2022 Build Tools）
- 打包：Inno Setup 6.7.3（用户级安装）

## 1. 构建与 manifest

```text
build\build.bat dev
→ dist\AccelBall-dev.exe（230,912 字节，manifest asInvoker）

build\build.bat release
→ dist\AccelBall.exe（230,912 字节，manifest requireAdministrator）

ISCC.exe installer\accel-ball.iss
→ dist\AccelBall-Setup-1.0.0.exe（2,241,243 字节）
```

manifest 提取（`mt.exe -inputresource:...;#1`）：

- 发布版：`requireAdministrator = true`，`PerMonitorV2 = true`
- 开发版：`asInvoker = true`，`PerMonitorV2 = true`

## 2. UI 与实时数据

- 启动开发版后窗口 124×124，位于工作区右侧；常驻 Working Set 约 12 MB。
- 桌面合成截图确认圆球外围透明，圆球内容为百分比、上行、下行三行；环形进度随占用变化。
- 同一时刻用 `GlobalMemoryStatusEx` 核对：程序显示 48%，系统返回 `dwMemoryLoad = 48`，一致。
- 连续截图观察到网速数值在 9 KB/s、564 B/s、4 KB/s、2 KB/s 等之间变化，说明按秒采样并刷新。
- 最终成品截图：36%，↑ 68 KB/s，↓ 11 KB/s。

## 3. 双击清理

- 向窗口发送 `WM_LBUTTONDBLCLK`，坐标 (62, 50)（百分比区域）。
- 约 1.4 秒后截图显示「已释放 2.7 GB」，内存从约 48% 降到 40%，程序未退出。
- 清理在后台线程执行；执行期间球上显示「正在清理…」，完成后显示释放量约 3 秒。
- 说明：本节为开发版（非管理员）测试，工作集回收生效；发布版以管理员运行，走同一清理路径并额外具备 standby list 清理权限。

## 4. 贴边收起与恢复

- 用真实鼠标事件从球心拖到屏幕右边缘（1920）并松手。
- 窗口变为 132×30，位于 (1788, 525)，横条显示绿点和「内存 34%」。
- 鼠标移入横条：窗口展开为 124×124，贴右边缘 (1796, 478)，显示完整圆球。
- 鼠标移出：约 0.45 秒后恢复为 132×30 横条。
- 贴边状态写入 `%APPDATA%\AccelBall\config.ini`，重启后按该状态恢复。

## 5. 右键菜单、单实例与退出

- 右键横条/圆球弹出原生菜单：「立即清理内存」「退出」；按 Esc 可关闭，进程继续运行。
- 启动第二个开发版实例：1 秒内自行退出（退出码 0），系统中始终只有一个进程。
- 发送 `WM_CLOSE` 优雅退出：退出码 0，配置已写入（`edge=2, along=540, mode=bar`）。
- 退出路径曾因静态 GDI+ `FontFamily` 在 `GdiplusShutdown` 之后析构而崩溃（0xC0000005），已改为进程级不析构指针，复测退出码 0。

## 6. 安装包与提权发布版

- 静默安装：`AccelBall-Setup-1.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`，UAC 通过，安装程序退出码 0。
- 安装结果：`C:\Program Files\AccelBall` 下存在 `AccelBall.exe`（230,912 字节）、`README.md`、`unins000.exe`；开始菜单组「加速球」含「加速球.lnk」「卸载加速球.lnk」。
- 提权启动：UAC 通过，`AccelBall.exe` PID 32956，窗口 132×30 @ (1788, 525) 可见，Working Set 11.6 MB；按上次配置以贴边横条启动。
- 提权窗口无法被非提权截图工具捕获（Windows UIPI 预期行为），发布版界面由用户目视验收；功能代码与开发版一致。

## 7. 未覆盖项

- 高负载下的网速精度未与系统计数器做严格对比，仅确认数值随真实流量变化。
- 本机未做清理前后的性能 A/B 测试；只验证了可用内存与显示占比的变化。
