## 2. 尺寸与 UI

- 按用户反馈经历 124px → 52px → 74px 两次调整；最终球径 74px，为原 124px 的 60%。
- 百分比字号 18px（粗体），上下行字号 9px，网速使用 `K/s`、`M/s` 紧凑单位。
- 同一时刻用 `GlobalMemoryStatusEx` 核对：程序显示 48%，系统返回 `dwMemoryLoad = 48`。
- 限速下载期间实际截到 `↓ 22.3M/s`，74px 下网速清晰可读。
- 进程常驻：74px、96 DPI 下约 11.4 MB RSS / 2.5 MB private / 5 线程。

## 3. 双击清理

- 在 74px 圆球百分比区域发送 `WM_LBUTTONDBLCLK`。
- 约 1.5 秒后截图显示「释放 768M」，内存从 33% 降到 31%，程序未退出。
- 清理在后台线程执行；执行期间显示「清理中…」，完成后显示释放量约 3 秒。

## 4. 贴边、悬停与命中

- 拖到右边缘：30×74 竖向条，显示「点 + 竖排内存 + 百分比」。
- 拖到上边缘：74×30 横向条，显示「点 + 内存 xx%」。
- 鼠标移入贴边条：展开为 74×74 圆球；移出约 0.45 秒后恢复贴边条。
- 悬停展开时，球外那段贴边条区域绘制了一层 alpha=1 的不可见底；`WindowFromPoint` 在条端（如右侧条顶部、右端）均返回本窗口，解决了分层窗口 alpha=0 区域点击穿透的问题。
- 贴边状态与位置写入 `%APPDATA%\AccelBall\config.ini`，重启后恢复。

## 5. 右键菜单、单实例与退出

- 右键球/贴边条弹出原生菜单：「立即清理内存」「退出」；Esc 可关闭。
- 第二实例 1 秒内退出（退出码 0）；开发版使用独立互斥名与 `config-dev.ini`，可与发布版并行。
- 优雅退出退出码 0；此前静态 GDI+ `FontFamily` 在 `GdiplusShutdown` 后析构导致 0xC0000005，已改为进程级不析构指针，复测通过。

## 6. DPI 与多显示器

- manifest 为 PerMonitorV2；代码处理 `WM_DPICHANGED`、`WM_DISPLAYCHANGE`、`WM_SETTINGCHANGE(SPI_SETWORKAREA)`，按最近显示器工作区定位并夹取。
- 开发版用 `ACCELBALL_DPI` 强制缩放实测（不改系统设置、发布版不读取该变量）：

| 强制 DPI | 球径 | 内存 RSS / private / 线程 |
|---|---|---|
| 96 | 74px | 11.4 MB / 2.5 MB / 5 |
| 120 | 93px | 11.6 MB / 2.6 MB / 5 |
| 144 | 111px | 11.6 MB / 2.5 MB / 5 |
| 192 | 148px | 11.7 MB / 2.6 MB / 5 |

- 150% 下截取 111px 球和 45×111 竖条，文字无裁切。
- 本机只有 100% 单屏，真实「跨显示器 DPI 切换」和多显示器硬件场景未实测。

## 7. 网速精度对照

- `tools/net_probe.cpp` 打印每块接口的 `HardwareInterface`、状态、累计字节与过滤结果。
- 本机 `GetIfTable2` 返回大量 WFP/QoS 过滤接口和虚拟接口：only `WLAN`（Intel Wi-Fi 6 AX200，type=71，hw=1，up=1）进入求和；FlClash/Meta Tunnel（hw=0）、WFP/QoS 过滤接口（hw=0）、loopback、WAN Miniport 均被排除，**没有重复计数**。
- 用 curl `--limit-rate 2m` 下载 24 MB：curl 自身平均 1,998,686 B/s；同一秒探针读到 WLAN 合计 23,705,821 B/s，界面显示 22.3 M/s。差额来自其他进程的真实流量（探针与界面一致），说明显示的是全主机物理网卡合计，不是单进程流量。
- 结论：计数逻辑与系统累计字节一致；高读数可能是其他应用/系统更新造成，不是悬浮球重复统计。

## 8. 安装包与提权发布版

- 静默覆盖安装：`AccelBall-Setup-1.0.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART`，UAC 通过，安装程序退出码 0。
- 安装结果：`C:\Program Files\AccelBall\AccelBall.exe` 231,936 字节、`README.md` 5,681 字节、`unins000.exe`；开始菜单组「加速球」含「加速球.lnk」「卸载加速球.lnk」。
- 提权启动：UAC 通过，`AccelBall.exe` PID 580，窗口 74×74 可见，Working Set 11,184 KB。
- 提权窗口无法被非提权截图工具捕获（Windows UIPI 预期行为），发布版界面由用户目视验收；功能代码与开发版一致。

## 9. 未覆盖项

- 多显示器硬件场景与真实跨屏 DPI 切换未实测；只用强制 DPI 验证了布局缩放。
- 高负载网速精度依赖全主机流量，未做逐进程归因（工具本身只显示全主机合计）。
- 本机未做清理前后的性能 A/B 测试；内存清理不保证提速，这是此类工具的物理边界。
